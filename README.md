# Audio Machine

Static browser app. No build step.

## Run

Open [index.html](./index.html) in a browser, or serve the folder with any static file server.

## Structure

- `audioapp/app.js`: shell, routing, notifications
- `audioapp/slowed.js`: Slowed + Reverb
- `audioapp/grossbeat.js`: Gross Beat
- `audioapp/funmachine.js`: Fun Machine
- `audioapp/piano.js`: Piano
- `audioapp/about.js`: About page
- `audioapp/shared.js`: shared audio/browser helpers
